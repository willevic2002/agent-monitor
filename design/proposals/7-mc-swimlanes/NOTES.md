Idea: flight-recorder swimlanes instead of a brain: one lane per agent (lead first), time left->right with "now" at the right edge, each tool call a tick (amber running, grey done, red error); subagent lanes start at spawn and end when done. Plain 2D canvas, no three.js; fed by logLine/tool_result/renderAgents/pulse.
Layout C: header + stats strip, full-width lanes band (33%), below it chat (60%) | tool-call log (40%); lane labels (#agents) carry code, name, status, tools, tokens. Phone: stacked, lane labels shrink to code+name.
Palette: graphite #0d0e10, white data, amber #e8a317 accent, red only for errors; agent codes use an amber/white/grey family.
Known flaws: time window is auto-fit (min 12 s), so a short session bunches at the right; log is bottom-anchored so it looks empty early; only tool calls and Agent dispatches become ticks (no thinking/text); design-shots.mjs reports a harmless first-load "getContext of null" pageerror (the login redirect serves the repo's brain.html); small-caps labels are 12px so lowercase renders ~10px.
